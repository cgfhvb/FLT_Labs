# Лабораторная работа №1 (Рефал). Вариант 3

Везде в задачах подразумевается, что строка - в алфавите латинских строчных букв, переменная - в алфавите заглавных латинских, строка окружена маркерами начала `^` и конца `$`.
Образцы в левых и правых частях правил даются исчерпывающе: `^P1$ = ^P2$`, где `P2` не содержит свежих переменных, не входящих в `P1`.
Подразумевается, что получившиеся системы переписывания строк должны быть эквивалентны системам переписывания образцов именно по модулю слов, имеющих представление `^[a-z]*$`.

**Образцы с единственной переменной, недетерминизм.**
Даны несколько правил переписывания образцов, содержащих одну переменную, но возможно, большей, чем единица, кратности как слева, так и справа.
Построить систему переписывания строк, эквивалентную этим правилам, учитывая, что правила могут применяться в любом порядке.

## Идея решения

1. **Выбор правила.** `^ → L Q<r>_0_p` для каждого правила `r`. Пока идёт
   вычисление, `^` в строке нет, поэтому применение второго правила не может начаться до завершения первого.
2. **Префикс.** Константы до первого X проверяются и стираются: `Q_i_p a → Q_{i+1}_p`.
3. **Первое вхождение X.** Каретка либо добавляет к нему очередную букву
   (`Q_i_p a → a Q_i_p`), либо ставит после него границу `D`. Это единственное
   место недетерминизма внутри правила. Строка принимает вид `L x D Q хвост $`.
4. **Остаток левой части.** Константы проверяются и стираются. Для каждого
   следующего X каретка возвращается к `L`, берёт очередную непомеченную букву первого вхождения X,
   помечает её (`c → Mc`), переносит её за `D` и стирает такую же букву хвоста.
   Когда помечены все буквы первого вхождения, пометки снимаются. Если буква не совпала, вычисление по этой ветке не продолжается.
5. **Конец слова.** После всей левой части должен стоять `$`:
   `Q_n_p $ → H Q_0_o $`. `H` отделяет будущий результат.
6. **Правая часть.** Константы дописываются перед `$`. Для X копируется первое вхождение
   тем же проходом, что и при сравнении, только буква переносится до `$` и вставляется перед ним.
7. **Очистка.** `Q_m_o → Z`, `Z` перемещается влево до `H`, `H Z → E`, `E` стирает
   первое вхождение X и `D`, `L E → ^`.

Сравнение и копирование X выполняет один и тот же проход по первому вхождению X (функция `Scan`).
Они различаются только действием над перенесённой буквой (`Transfer`).
Счётчик длины X не нужен, т.к. длину определяет граница `D`, выбранная недетерминированно.

## Обозначения

| Символ | Значение |
|---|---|
| `L` | начало рабочей строки, стоит на месте `^` во время вычисления |
| `D` | конец первого вхождения X |
| `H` | начало собираемого результата |
| `Mλ` | помеченная буква λ первого вхождения X (уже обработана в текущем проходе) |
| `Q<r>_<i>_p` | проверка левой части правила `r`, позиция `i` |
| `Q<r>_<i>_o` | построение правой части правила `r`, позиция `i` |
| `Q<r>_<i>_Compare…` | сравнение очередного вхождения X с первым |
| `Q<r>_<i>_Copy…` | копирование первого вхождения X в результат |
| `…back`, `…read` | возврат к `L` и поиск непомеченной буквы первого вхождения X |
| `…carryλ`, `…targetλ` | перенос буквы λ к месту сравнения / вставки |
| `…restore`, `…forward` | снятие пометок и возврат к рабочей позиции |
| `Z`, `E` | очистка: проход к `H` и стирание первого вхождения X |
